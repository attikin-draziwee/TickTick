## Разработка на Axum + SQLx

Чтобы протестировать или «пощупать» проект на своём ПК, необходимо:

1. Создать файл-окружение `.env`:

   ```bash
   .
   ├── README.md # Вы здесь
   …
   └── dev
       ├── api
       │   ├── .env # ← Здесь его нужно создать    
   	…
       │   ├── src
       │   └── target
       └── compose.yml
   ```

   ```bash
   # Содержимое файла по умолчанию. Если меняете данные - не забудьте поменять их в compose.yml файле!
   DATABASE_URL=mysql://admin:c9j74_b2_01eMD@localhost:3306/todo
   PORT=8080
   ```

2. Поднять базу данных

```bash
# Переместиться на уровень с docker compose файлом.
cd ./dev/
docker compose up -d db
```

2. По желанию установить утилиту `sqlx`:

```bash
cargo install sqlx-cli
# Попробовать сделать миграцию таблиц
cd ./dev/api
sqlx database create
sqlx migrate run
# sqlx database reset - стирает базу данных и пересоздаёт

```

3. Запустить `cargo watch -x run` (предварительно установив утилиту `cargo-watch`)
4. После того как вы убедились что все работает, необходимо закэшировать `sqlx::query_as!` макросы, которые проверяют валидность SQL-запросов на этапе компиляции. Делается это командой:

```bash 
# Данная команда создаёт папку с кэшами ./sqlx
cargo sqlx prepare
```

5. После кэширования slqx, можно запустить полноценно через docker:

```bash
cd ./dev/
docker compose up -d
```
